CSER — Continuous Speech Emotion Recognition

Present this as a system with modules, not a tiny smoother on top of a classifier.

Title-aligned definition:
Continuous SER means emotion is estimated as a time series over speech, then structured into stable states and change events, with evaluation for both recognition and transition detection — offline and online (causal) modes.

CSER modules (say these names)

CSER-D
Data & alignment
MELD labels ↔ dia*_utt*.wav audio; dialogue stitching for continuous streams.
CSER-F
Feature encoder
Log-mel + delta + delta-delta (how the voice changes over time).
CSER-M
Acoustic emotion model
CNN + BiLSTM, 7-class utterance SER (base recognizer).
CSER-C
Continuous inference
Dense 2 s / 1 s window predictions over the full dialogue audio.
CSER-T
Temporal structuring
Offline or causal smooth → stable regions → transition events.
CSER-E
Dual evaluation
(1) Utterance accuracy/F1  (2) Continuous recognition  (3) Transition detection F1.

Why this matches the title “Continuous SER”

Normal SEROur CSER
One clip → one emotionSpeech stream → emotion over time
No change eventExplicit transitions (emotion change detection)
Offline clip batch onlyOffline + causal/online mode (--mode causal)
Only classification scoreRecognition + transition metrics + timeline output
