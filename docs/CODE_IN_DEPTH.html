In-depth code explanation

Project: Continuous Speech Emotion Recognition on MELD audio.

Two execution paths share the same model:
(A) Training / test accuracy — one MELD utterance → one forward pass → one predicted class vs gold label.
(B) Continuous timeline — long audio → many 2 s windows → smooth → stable + transition segments. 
prepare_meld.py (data)     train.py → best_model.pt     evaluate.py (metrics)
                                    ↓
                         infer_timeline.py → temporal_tracking.py → JSON timeline

src/audio_utils.py — raw sound → numpy array

load_audio(path)

  1. Reads WAV with soundfile.
  2. If stereo → average channels to mono.
  3. If sample rate ≠ 16 kHz → librosa.resample.
  4. Returns float32 1-D array: samples over time.

prepare_waveform(audio) — used before features

  • If length > 6 s → keep first 6 s only (MAX_DURATION).
  • If length < 1.5 s → pad zeros at end up to 1.5 s (MIN_DURATION).
  • Why: old code padded every clip to 6 s; the model learned silence, not speech.

extract_wav(mp4, wav)

Used in prepare_meld.py: ffmpeg strips video, outputs mono 16 kHz WAV from MELD MP4 clips.

src/features.py — waveform → model input

waveform_to_features(audio)

  1. melspectrogram — power in 64 mel bands over time.
  2. power_to_db — log scale (log-mel).
  3. delta and delta order 2 — how bands change frame-to-frame.
  4. Each channel normalized: (x - mean) / std.
  5. Stack → shape (3, 64, T) where T depends on utterance length.

sliding_windows(audio, sr, win_sec, hop_sec)

Generator used only in infer_timeline.py:

  • Window size = 2 s × 16000 = 32000 samples.
  • Hop = 1 s → overlapping windows.
  • If audio shorter than window → pad once, yield one window at t=0.
  • Extra tail window if the last hop would miss the end.

save_feature_file

load WAV → prepare_waveform → features → save .npy for fast training epochs.

src/dataset.py — MELD PyTorch Dataset

load_split_csv(split)

Reads train_sent_emo.csv (or dev/test). Filters to 7 emotions. Builds clip_id like dia0_utt3 to match WAV filenames.

MeldMelDataset.__getitem__(idx)

  1. Get row → emotion string → label = EMO2IDX[emotion].
  2. Try load data/cache/{split}/{clip_id}.npy.
  3. Else: load WAV → prepare_waveform → waveform_to_features → optionally save cache.
  4. Return (tensor features, label, clip_id).

collate_pad(batch)

Utterances have different lengths → different T. This function pads all items in a batch to the max T in that batch, producing tensor shape (B, 3, 64, T_max). Labels become (B,).

src/cache_build.py

Before training, builds missing .npy files in parallel (ProcessPoolExecutor, up to 8 workers). Avoids recomputing mel+delta on every epoch (~10k train files).

src/model.py — CNNBiLSTM

Input

x shape (B, 3, 64, T) — batch, channels (mel/delta/delta2), mel bins, time frames.

SpecAugment (training only)

Randomly zeros small frequency bands and time bands → regularization, harder to overfit.

CNN block (3 stages)

Each stage: Conv2d 3×3 → BatchNorm → ReLU → MaxPool 2×2. Channels 3→32→64→128. Mel height 64 is pooled 3 times: 64→32→16→8 (freq_bins = 8).

Reshape for LSTM

Permute to (B, T', C*F) with T' = time after CNN pools and C*F = 128*8 = 1024 per time step.

BiLSTM

2 layers, hidden 128, bidirectional → 256 dims per time step. Reads sequence context inside the clip.

Pooling + classifier

0.5 * mean(time) + 0.5 * max(time) → vector 256 → Linear 256→128 → Dropout → Linear 128→7 logits.

predict_proba

eval() + softmax on logits → 7 probabilities summing to 1. Used in timeline inference.

scripts/train.py

Startup

  • --source meld → MeldMelDataset("train") and ("dev").
  • build_cache for train and dev.

Training options (important for your 49% model)

FlagsEffect
--sampler none --loss ceNatural MELD class mix + CrossEntropy with label_smoothing=0.05 → best test accuracy (~49%)
--sampler balanced --loss focal (default)Oversample rare classes + focal loss → better minority F1 but lower accuracy

run_epoch

  1. Forward: logits = model(mel).
  2. Loss vs true label.
  3. Backward + gradient clip max norm 5.
  4. Argmax prediction → collect for accuracy / weighted F1.

Checkpoint

Saves state_dict, emotions list, dev metrics. Best model copied to checkpoints/best_model.pt. Early stop if no improvement for EARLY_STOP_PATIENCE epochs (when using focal path).

scripts/evaluate.py

Loads best_model.pt, runs one forward pass per utterance (same as training), no sliding windows. Computes accuracy, weighted F1, confusion matrix → outputs/metrics/test_metrics.json.

This is official MELD-style utterance evaluation. Timeline is not scored here.

scripts/infer_timeline.py — demo path

load_model

Rebuild CNNBiLSTM(), load weights, eval() mode.

stitch_dialogue(split, dialogue_id)

Loads all utterances of one MELD dialogue in order, concatenates audio + 0.15 s silence between turns. Returns long waveform + metadata (gold emotion per turn, text snippet, start/end times).

predict_windows

For each sliding window: features → batch dim → predict_proba → argmax class + confidence. Lists: times, classes, confs.

Then

  1. majority_smooth(classes, confs) from temporal_tracking.
  2. build_timeline(times, smooth).
  3. format_timeline printed; full JSON saved under outputs/timelines/.

src/temporal_tracking.py — your contribution in code

majority_smooth

For each window index i:

  • Look at neighborhood of size k=3.
  • If i is a spike (different from both neighbors) AND conf[i] < MIN_CONF → replace with previous label.
  • Else set to majority vote in the window.

build_timeline

Walk smoothed labels. When label changes at time t:

  1. Close stable segment [start, t] for old emotion.
  2. Add transition [t, t+0.5] from old → new.
  3. Next stable starts at t+0.5.

Finally merge adjacent stable segments with same emotion. TimelineSegment.as_dict() for JSON export.

Tensor / data shapes cheat sheet

Raw audio (1 utterance)     : (N_samples,)     e.g. 2.5 s → 40000 samples
After prepare_waveform      : (N_samples,)     capped/padded
Features                    : (3, 64, T)
Batch after collate_pad     : (B, 3, 64, T_max)
CNN output (internal)       : (B, 128, 8, T')
LSTM sequence               : (B, T', 1024) in, (B, T', 256) out
Pooled vector               : (B, 256)
Logits                      : (B, 7)
Softmax                     : (B, 7) probabilities

Timeline: one row per 1 s hop (approx), not per sample

What to say when they point at code

“Where is novelty?” → temporal_tracking.py + window loop in infer_timeline.py. Not in CNN layers.

“Where is MELD?” → dataset.py reads MELD CSV + data/meld/audio WAVs.

“Where is mel spectrogram?” → features.py waveform_to_features.

“Where is accuracy computed?” → evaluate.py utterance-level argmax vs label.

“Why two train modes?” → balanced+focal for research on rare classes; ce+natural sampling for higher accuracy on imbalanced test set.
